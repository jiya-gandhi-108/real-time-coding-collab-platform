# Real-Time Coding Collaboration Platform

A full-stack real-time collaborative coding platform that allows multiple users to join a room, edit code together, chat, and see live activity updates.

This project is built to demonstrate real-time systems, authentication, and collaborative workflows using modern web technologies.

---

## 🚀 Features

- Real-time code collaboration using WebSockets
- Multiple users editing the same room simultaneously
- Live join/leave and editing notifications
- Authentication with protected routes
- Chat functionality inside rooms
- Room-based collaboration system
- Clean separation of frontend and backend

---

## 🛠 Tech Stack

### Frontend
- React
- Context API
- Socket.IO Client
- CSS

### Backend
- Node.js
- Express
- Socket.IO
- MongoDB (via Mongoose)
- JWT Authentication
